# 任务 3: 数据与评估

任务概览：整理主流多模态数据集和评估指标体系。系统提示：关注benchmark建设、跨模态对齐评估方法。来源概览：数据集官网、评估平台、研究论文。
任务总结：
1. 多模态评测体系正从单一感知向“感知-推理-应用”深度融合的分层架构演进。
2. 评估指标呈现“客观自动化”与“主观/LLM辅助”并重的双轨制，以应对生成式任务的复杂性。
3. 数据集构建强调“反污染”与“高难度”，通过动态更新和专家级题目突破模型能力上限。
4. 细粒度与特定领域评测成为新热点，填补通用Benchmark在OCR、图表、文化等垂直场景的盲区。
