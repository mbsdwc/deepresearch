# 任务 3: 技术架构创新

任务概览：研究多模态模型架构的创新和关键技术进展
系统提示：需要分析多模态模型架构的创新点，如Transformer、注意力机制、跨模态融合等
来源概览：将检索学术论文、技术白皮书和架构设计文档
任务总结：梳理2025年多模态模型架构的关键创新和技术演进

## 关键发现

### 1. 多模态Transformer架构的两大主流范式
- **后接模块方案**：以LLaVA为代表，采用"视觉编码器→多模态投影器→大型语言模型"架构，训练成本低（仅需数十GPU天），模块化灵活
- **原生多模态方案**：以Google Gemini 1.5为代表，采用"离散标记器/编码器→多模态Transformer/解码器"架构，从预训练阶段就让模型同时学习所有模态

### 2. 视觉-语言桥接的三种主流方案
- **线性投影**：LLaVA首创，用1-2个全连接层将视觉特征映射到LLM嵌入空间，参数量小（数百万级），视觉信息无损保留
- **Q-Former**：BLIP-2提出，使用32个可学习查询向量通过交叉注意力提取视觉信息，将数百个视觉词元压缩到32个
- **Perceiver Resampler**：Flamingo提出，使用64-128个潜变量，模态无关性更强

### 3. 跨模态注意力的三种方案
- **全交互（Early Fusion）**：所有模态词元放在同一序列中使用标准自注意力，Gemini采用此方案
- **交叉注意力（Cross-Attention）**：在LLM特定层插入交叉注意力模块，文本词元查询视觉词元，Flamingo采用此方案
- **Perceiver架构**：引入可学习潜变量词元，所有模态信息先汇聚到潜变量中再提取

### 4. 高分辨率图像输入的创新解决方案
- **MiniCPM-V**：采用自适应图像划分和二维位置嵌入插值
- **InternVL1.5**：使用PixelShuffle技术减少标记大小
- **Qwen2-VL**：通过在ViT后添加额外MLP并使用二维旋转位置编码（2D RoPE）支持更大图像输入

### 5. 统一多模态理解与生成模型的三大架构范式
- **基于扩散的模型**：如DiT、SD 3.0等，采用UNet与Transformer架构
- **基于自回归的模型**：如LLaVA、Qwen-VL等，基于大型语言模型改编的Transformer骨干网络
- **融合自回归与扩散机制的混合方法**：如Transfusion、MonoFormer、LMFusion、Show-o等
