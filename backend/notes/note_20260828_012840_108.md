# 研究报告：2025年多模态的进展

# 2025年多模态的进展研究报告

## 1. 背景概览

多模态AI技术作为人工智能领域的重要发展方向，在2025年取得了显著进展。随着深度学习技术的不断突破，多模态AI已从单一模态处理向跨模态理解与生成能力飞跃发展，实现了从实验室研究到产业应用的快速转化。2025年，多模态AI在架构创新、高分辨率图像处理、跨模态理解与生成等方面取得了重大突破，同时在医疗健康、金融风控、自动驾驶、智能客服等多个行业领域实现了规模化落地应用，标志着多模态技术正从理论研究阶段迈向实用化、普及化发展阶段。

## 2. 核心洞见

1. **多模态AI架构实现从分离到融合的重大转变** [任务1]
   - 2025年形成了两种主流技术路线：多模态大语言模型(MLLM)采用"视觉编码器→多模态投影器→大型语言模型"架构；多模态标记化Transformer采用"离散标记器/编码器→多模态Transformer/解码器"架构，代表了多模态AI从简单模态融合向深度架构整合的转变。

2. **高分辨率图像处理技术取得突破性进展** [任务1]
   - MiniCPM-V、InternVL1.5、Qwen2-VL等模型通过自适应图像划分、PixelShuffle技术和二维旋转位置编码(2D RoPE)等技术，有效解决了多模态模型处理高分辨率图像的核心瓶颈。

3. **多模态AI在医疗和金融领域实现显著应用效果** [任务2]
   - 医疗领域诊断准确率达到91.1%，诊断效率提升约35%，减少约20%的人为误诊率；金融领域风控效率提升40%，欺诈识别率提升32%，误报率降低28%。

4. **银行业和智能客服成为多模态AI应用最领先的领域** [任务2]
   - 银行业2025年H1成为大模型应用占比最高的行业，达到18.1%；智能客服场景占比最高，达到22.1%，且部分企业已开展对客使用。

5. **多模态文生视频技术和端侧多模态模型成为未来重要发展方向** [任务1]
   - 谷歌Veo 2、快手可灵AI等模型将在视频生成领域展开角逐；技术路线从"压缩大模型"转向"优化小模型"，使端侧多模态AI在资源受限的边缘设备上也能高效运行。

## 3. 证据与数据

### 技术突破与模型进展

- **架构创新**：Google的PaliGemma采用"视觉编码器→多模态投影器→大型语言模型"架构；Google的Gemini 1.5采用"离散标记器/编码器→多模态Transformer/解码器"架构 [任务1]

- **高分辨率图像处理**：
  - MiniCPM-V采用自适应图像划分和二维位置嵌入插值技术
  - InternVL1.5使用PixelShuffle技术减少标记大小
  - Qwen2-VL通过在ViT后添加额外MLP并使用二维旋转位置编码(2D RoPE)支持更大图像输入 [任务1]

- **跨模态理解与生成**：
  - 3D视觉正从优化依赖转向端到端学习，华人学者在基础架构创新(如VGGT、SSS)方面表现突出
  - 厦门大学L4DR模型提出的跨模态和模态内并行特征提取主干，结合多尺度门控融合模块，有效应对恶劣天气条件下不同传感器数据质量差异退化的问题 [任务1]

### 行业应用与落地效果

- **医疗健康领域**：
  - 蚂蚁集团"医疗AI驱动的全流程健康管理平台"在MedBench评测中以98.9分、94.7分夺得自测和评测双榜冠军
  - 京东健康"AI京医"系统实现5分钟内完成百万级病例比对，服务满意度超95% [任务1]
  - 多模态AI诊断准确率达到91.1%，诊断效率提升约35%，减少约20%的人为误诊率 [任务2]

- **金融领域**：
  - 多模态AI风控效率提升40%，欺诈识别率提升32%，误报率降低28% [任务2]
  - 中国工商银行利用DeepSeek-R1大模型升级AI财富助理，通过客户洞见、产品洞见和通用问答三大能力突破
  - 邮储银行开发的AI交易机器人"邮小宝"和票据业务机器人"邮小盈"，提升交易效率、节约人力成本 [任务2]

- **自动驾驶领域**：
  - 比亚迪"天神之眼"高阶智能驾驶系统融合视觉、激光雷达、毫米波雷达等多模态传感器数据
  - 华为乾崑智驾系统通过多模态大模型"端到端2.0"VLA减少重复数据与计算资源 [任务1]

- **制造行业**：
  - 鑫海化工大模型、中国钢研金相分析大模型、海螺水泥建材行业大模型等在研发设计、生产制造、运营管理、设备维护等环节均有应用 [任务2]
  - 中国钢研金相分析大模型能够同时处理图像数据和工艺参数，实现材料性能的精准预测和优化 [任务2]

### 未来发展趋势

- **多模态文生视频技术**：谷歌Veo 2、快手可灵AI、minimax海螺AI等模型将在视频生成领域展开角逐，能产出更高分辨率、更高帧率的视频内容 [任务1]

- **量子计算赋能**：谷歌量子芯片willow的发布预示着量子计算时代的加速到来，量子计算的并行计算能力将指数级提升多模态模型的训练效率 [任务1]

- **端侧多模态模型**：技术路线从"压缩大模型"转向"优化小模型"，使得端侧多模态AI在资源受限的边缘设备上也能高效运行 [任务1]

- **具身多模态智能**：AI系统将不再局限于虚拟空间的交互，而是通过机器人、XR设备等载体在真实物理世界中实现多模态感知、理解与行动 [任务1]

## 4. 风险与挑战

由于任务3（性能评估与基准测试）、任务4（挑战与局限性）和任务5（未来发展趋势）的执行状态为"skipped"，暂无相关信息。基于已有信息，可以推测多模态AI技术可能面临的挑战包括：

1. **技术整合复杂性**：多模态架构从分离到融合的转变虽然提升了性能，但也增加了模型训练和优化的复杂性。

2. **计算资源需求**：高分辨率图像处理和跨模态理解需要大量计算资源，可能限制在资源受限环境中的应用。

3. **数据质量与多样性**：多模态AI的性能高度依赖于训练数据的质量和多样性，不同模态数据的质量差异可能影响模型表现。

4. **实际应用场景适应性**：虽然多模态AI在实验室环境中表现出色，但在复杂多变的实际应用场景中仍面临适应性挑战。

5. **伦理与安全问题**：多模态AI可能面临数据隐私、算法偏见、内容生成安全等伦理和安全问题。
